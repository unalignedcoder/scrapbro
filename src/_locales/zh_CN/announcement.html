ScrapBro 1.0.1

  • 新增：ScrapBro 现支持 13 种语言：英语、法语、德语、西班牙语、意大利语、巴西葡萄牙语、俄语、乌克兰语、波兰语、土耳其语、中文、日语和韩语
  • 新增：侧边栏使用系统颜色并跟随浏览器的浅色或深色主题，可从已安装的字体中选择字体
  • 新增：后端程序从与此版本对应的发布版本下载，保存前会校验其 SHA-256 校验和
  • 新增：安装步骤更清晰，每个文件只需保存一次到任意位置，并可一键重新开始
  • 新增：侧边栏中的安装按钮，首次运行时设置会打开安装页面
  • 新增：保存页面的编辑栏带有图标、更清晰的名称（删除元素、高亮、在侧边栏中显示）和提示
  • 新增：导出工具会显示页面导出的位置，或导出失败的原因
  • 更改：在 Firefox 中可以正常捕获并使用编辑栏，在 Chrome 中可以使用编辑栏
  • 更改：设置的导入和导出只使用当前的设置，并跳过已废弃的设置
  • 更改：设置页面保持相同大小，并适应任意窗口宽度

    • ScrapBro 1.0.0

    ScrapBro 的第一个版本，它是 ScrapBee 的分支，读写相同的数据。

  • 新增：可在 Chromium 浏览器（Chrome、Edge、Brave、Vivaldi）以及 Firefox 及其衍生版本（Floorp、LibreWolf、Waterfox）中运行
  • 新增：自带后端程序 scrapbro_backend，从 GitHub 上的 ScrapBro 发布版本下载。兼容现有数据，拒绝来自网页的请求，安全保存文件，崩溃不会留下写了一半的 RDF
  • 新增：后端端口自动选择，无需设置，端口被占用时会自动换一个
  • 新增：安装更简单：三个文件保存到任意位置，一个安装脚本，无需管理员权限
  • 新增：可以导入从 ScrapBee 导出的设置
  • 新增：设置中的调试选项会在日志中显示详细信息（后端消息、保存的文件、捕获步骤）
  • 新增：设置页面更清晰，安装步骤会显示文件的保存位置
  • 更改：路径中含有空格或括号的数据现在也能显示网页图标
  • 更改：捕获失败时会显示原因，不再锁住页面，也不会在侧边栏留下未完成的条目
  • 注意：请勿在同一浏览器中同时使用 ScrapBro 和 ScrapBee，它们会写入相同的文件
