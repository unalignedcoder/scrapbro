Che cos'è ScrapBro?

ScrapBro salva pagine web, o parti di esse, sul tuo disco e le organizza nella barra laterale del browser. Legge e scrive i dati di ScrapBook e di ScrapBee, di cui è un fork, quindi gli scrapbook esistenti continuano a funzionare. Funziona in Chrome, Edge, Brave, Vivaldi e negli altri browser Chromium, e in Firefox e nei suoi derivati.

Importante: non usare ScrapBro e ScrapBee nello stesso browser. Entrambi scrivono negli stessi file, usarli insieme può far perdere modifiche o danneggiare uno scrapbook. Per passare a ScrapBro, esporta le impostazioni da ScrapBee, rimuovilo e poi importale qui. Prima fai un backup delle cartelle degli scrapbook.

Come si usa

  • Prima del primo utilizzo

    • Installa il programma backend come descritto nella pagina Installazione, poi aggiungi i tuoi file RDF nella pagina Configurazione (vedi sotto).

  • Salvare

    • Apri ScrapBro nella barra laterale (pulsante della barra degli strumenti, poi «{OPEN_IN_SIDEBAR}»), seleziona la cartella per i nuovi elementi, poi fai clic destro sulla pagina: {CapturePage}, {CaptureSelection} (prima seleziona del testo), {CaptureUrl} o {CaptureAdvance}. Le stesse azioni sono nel pulsante della barra degli strumenti, che può anche salvare tutte le schede aperte («{CaptureTabs}»).

    Tieni aperta la barra laterale durante il salvataggio (tranne per il salvataggio avanzato). Un nuovo elemento mostra un'icona che gira finché la pagina non è salvata. Gli elementi si possono spostare trascinandoli.

  • Leggere e modificare

    • Fai clic su un elemento per aprire la pagina salvata. La barra in fondo a una pagina salvata permette di evidenziare il testo, togliere le parti indesiderate, modificarla e salvare le modifiche. Il piccolo pulsante accanto a un elemento apre l'indirizzo originale della pagina.

    File RDF

    Un file RDF è l'indice di uno scrapbook: elenca elementi e cartelle, e le pagine salvate si trovano nella cartella «data» accanto a esso. Puoi avere più file RDF, ognuno compare nell'elenco in cima alla barra laterale.

    Nella pagina Configurazione fai clic su «+», inserisci un nome e il percorso completo del file RDF, per esempio C:\scrapbooks\news\scrapbook.rdf o /home/io/scrapbooks/news/scrapbook.rdf. Un file che non esiste ancora viene creato vuoto.

    Avviare il backend da sé

    Normalmente ScrapBro avvia il programma backend da solo («Automaticamente» nella pagina Configurazione) e sceglie una porta libera. Per avviarlo tu, per esempio come servizio, scegli «Manualmente», inserisci il suo indirizzo e avvialo con:

    scrapbro_backend web-server [porta] [host] [password]
    per esempio scrapbro_backend web-server 9901 127.0.0.1

    Una password (solo lettere e cifre) protegge il backend, la stessa password va inserita nella pagina Configurazione.

    Risoluzione dei problemi

    Per prima cosa attiva Debug nella pagina Configurazione e guarda il Registro: mostra i messaggi scambiati con il backend, ogni file salvato e ogni passo del salvataggio, con l'errore quando qualcosa non va.

    La barra laterale dice che il backend non è in esecuzione

    Di solito il Registro ne indica il motivo:

  • Specified native messaging host not found: lo script di installazione non è stato eseguito, oppure il file di configurazione è stato spostato dopo. Metti il programma, il file di configurazione e lo script di installazione in un'unica cartella ed esegui di nuovo lo script.
  • Access to the specified native messaging host is forbidden: il file di configurazione appartiene a un'altra copia di ScrapBro. Succede quando l'estensione è stata rimossa e aggiunta di nuovo, il che può cambiarne l'ID: scarica di nuovo il file di configurazione (Installazione, passo 2) ed esegui lo script.
  • Backend disconnected subito dopo l'avvio: il programma manca o è bloccato, controlla che sia accanto al file di configurazione e che nessun software di sicurezza lo abbia rimosso.

    • Dopo ogni modifica, disattiva e riattiva ScrapBro nella pagina delle estensioni del browser.

    Il browser blocca il download del programma

    I browser avvisano per i programmi ancora poco scaricati. Apri la pagina dei download del browser e scegli di conservare il file. Puoi anche scaricarlo qui: scarica il programma backend.

    Un software di sicurezza segnala il programma

    Alcuni antivirus segnalano piccoli programmi non firmati come il backend. Aggiungilo alle eccezioni dell'antivirus se viene bloccato o rimosso.

    Uno scrapbook non si carica o non si può salvare

  • Controlla che il percorso nella pagina Configurazione sia corretto e che il file RDF esista.
  • Tieni gli scrapbook in una cartella in cui il tuo utente può scrivere, per esempio non direttamente in C:\ su Windows.
  • Se il Registro mostra «failed to load ... 404», il backend non ha trovato il file: controlla il percorso.

    • Porta

    In modalità automatica ScrapBro sceglie la porta e ne prende un'altra se è occupata, la pagina Configurazione mostra quella in uso. In modalità manuale, se il backend segnala «address already in use», avvialo su un'altra porta.

    Ancora non funziona?

    A volte riavviare il browser aiuta. Altrimenti segnala il problema con le righe del Registro su github.com/unalignedcoder/scrapbro.

    Backup

    Fai regolarmente un backup delle cartelle degli scrapbook (file RDF e cartelle «data»), ScrapBro non salva copie delle pagine salvate. Prima di salvare un file RDF, ne conserva una volta al giorno una copia della versione precedente in una cartella «backup» accanto a esso.
