ScrapBro是什么?

重要：请勿在同一浏览器中同时使用 ScrapBro 和 ScrapBee。两者写入相同的文件，同时使用可能丢失修改或损坏数据。切换时，请先从 ScrapBee 导出设置，卸载 ScrapBee，然后在这里导入。使用前请先备份数据目录。

ScrapBro 是一个继承了一些ScrapBook特性的火狐Quantum扩展， 至少，它可以读写ScrapBook遗留下来的的文档(当然，也可以新建)。
由于ScrapBook没有支持火狐Quantum，所以在期望中，ScrapBro是一个用于部分替代ScrapBook的火狐Quantum扩展.

有了ScrapBro，您可以保存网页内容到本地存储，并且可以在火狐侧边栏中进行管理。

安装和运行后端程序

ScrapBro需要运行一个专用的"后端程序"才能正常工作。 有两种方式安装和运行后端程序，分别为自动或者手动运行，请任选其一。

  • 安装

    • 1. 自动
    在 安装 引导页面为自动运行方式安装后端程序。

    2. 手动
    点击 源1 下载后端程序到硬盘。

  • 设置

    • 1. 自动
    只需要输入一个希望程序监听的端口, 确保端口没有被其它程序占用。默认为 9900。

    2. 手动
    需填入后端 web 服务地址, 形式：http://[host]:[port], 默认为： http://127.0.0.1:9901。

  • 运行

    • 1. 自动
    启动火狐时，后端程序会自动随之运行。

    2. 手动
    在运行火狐之前，需要以命令行方式手工启动后端程序。

    命令形式为：scrapbro_backend web-server [port] [host]

    例如 (Windows)：
    cd D:\Download
    scrapbro_backend web-server 9901 127.0.0.1

    Linux 或 Mac:

    cd ~/Download

    确保为程序添加了可执行权限：
    chmod +x scrapbro_backend

    ./scrapbro_backend web-server 9901 127.0.0.1

  • 密码
    • 可以设置密码使后端服务更安全，密码只能包含数字0-9和字母a-z。

    1. 自动
    只需要输入密码并保存。

    2. 手动
    输入密码并保存，还需要在运行后端程序时添加密码参数：
    scrapbro_backend web-server [port] [host] [password]

    以 Windows 为例:
    scrapbro_backend web-server 9901 127.0.0.1 secret

    RDF文件

    RDF文件是ScrapBro及ScrapBook的主要数据文件，用于登记已下载数据的各类相关信息。同时，下载内容被保存到同一目录下的"data"文件夹。

  • 设置

    • 在使用前必需设置rdf文件，并且可以设置多个，分别设置名称和绝对路径(见下图)，这些名称将显示在侧边栏顶部的下拉列表中。

    使用

    点击ScrapBro图标，在测边栏中打开ScrapBro（图示1），需要的话，在侧边栏中新建所需文件夹（图示2）

    打开并充分加载想保存的网页内容，在其上通过右键菜单抓取页面（图示3）

    您也可以保存选中的局部内容，通过右键菜单抓取选区（图示4）

    抓取内容时，将在侧边栏中显示相应条目（图示5），并且其图标为等待状态，直到抓取完成，这时可以通过点击条目打开本地内容（图示6），也可以通过点击原始地址按钮（图示7），打开原始链接

    请注意

    无论抓取什么内容，都请保持ScrapBro在侧边栏中打开（高级保存除外），抓取内容将保存到ScrapBro侧边栏中当前所选位置（如果没有选中任何文件夹，将保存到顶层目录）。另外，您可以在抓取内容后通过拖动来移动条目位置。

    问题解决

    端口

    如果ScrapBro工作不正常, 同时发现在日志窗口中有:
    error: listen tcp :9900: bind: address already in use
    请手工结束占用此端口的进程（通常是火狐非正常退出时遗弃的ScrapBro后端进程），比如在Linux中你可以执行：
    fuser -k 9900/tcp
    或者在设置中换用其它端口

    文件系统权限

    请不要注册当前用户不具有读写权限的目录中的RDF文件， 比如，对于Windows，普通用户通常没有c:\目录的写权限，而像c:\foobar这样的子目录通常可行。

    安全软件误报

    ScrapBro的后端软件及安装脚本容易被杀毒、防木马软件误报为风险软件，请将ScrapBro后端列入其白名单来防止误报、误杀。如果您有好的改进方案，请联系我。

    下载安装脚本失败

    由于某些原因，比如安全软件，可能会影响后端安装脚本正常下载，此时请尝试重新下载:
    关闭火狐->删除“火狐下载目录/scrapbro/”中的所有文件->启动火狐->再次下载

    如果仍然失败，请在“火狐下载目录/scrapbro/”中尝试手工建立这些文件

    scrapbro_backend_firefox.json: (重要：请替换"火狐下载目录"为你的实际火狐下载目录)
    \{
    "allowed_extensions": [
    "scrapbro@tuscoss.com"
    ],
    "description": "ScrapBro backend",
    "name": "scrapbro_backend",
    "path": "火狐下载目录/scrapbro/scrapbro_backend",
    "type": "stdio"
    \}
    install.bat(Windows, CODEPAGE UTF-8):
    chcp 65001
    reg delete "HKEY_LOCAL_MACHINE\SOFTWARE\Mozilla\NativeMessagingHosts\scrapbro_backend" /f
    reg add "HKEY_LOCAL_MACHINE\SOFTWARE\Mozilla\NativeMessagingHosts\scrapbro_backend" /d "FIREFOX-DOWNLOAD-DIRECTORY\scrapbro\scrapbro_backend_firefox.json" /f
    reg delete "HKEY_CURRENT_USER\Software\Mozilla\NativeMessagingHosts\scrapbro_backend" /f
    reg add "HKEY_CURRENT_USER\Software\Mozilla\NativeMessagingHosts\scrapbro_backend" /d "FIREFOX-DOWNLOAD-DIRECTORY\scrapbro\scrapbro_backend_firefox.json" /f
    echo done
    pause
    install.sh(Linux)
    #!/bin/bash
    chmod +x scrapbro_backend
    dest="$\{HOME\}/.mozilla/native-messaging-hosts"
    if [ ! -d "$dest" ];then
        mkdir -p "$dest"
    fi
    cp scrapbro_backend_firefox.json "$dest/scrapbro_backend.json"
    echo done
    install.sh(Mac)
    #!/bin/bash
    chmod +x scrapbro_backend
    dest="$\{HOME\}/Library/Application Support/Mozilla/NativeMessagingHosts"
    if [ ! -d $dest ];then
        mkdir -p $dest
    fi
    cp scrapbro_backend_firefox.json "$dest/scrapbro_backend.json"
    echo done
