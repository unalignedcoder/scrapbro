ScrapBro 1.0.1

  • 새 기능: ScrapBro를 13개 언어로 사용할 수 있습니다: 영어, 프랑스어, 독일어, 스페인어, 이탈리아어, 브라질 포르투갈어, 러시아어, 우크라이나어, 폴란드어, 튀르키예어, 중국어, 일본어, 한국어
  • 새 기능: 사이드바는 시스템 색상을 사용하고 브라우저의 밝은/어두운 테마를 따르며, 글꼴은 설치된 글꼴에서 고릅니다
  • 새 기능: 백엔드 프로그램은 이 버전에 해당하는 릴리스에서 다운로드되며, 저장하기 전에 SHA-256 체크섬을 확인합니다
  • 새 기능: 명확한 단계의 설치, 각 파일은 원하는 곳에 한 번만 저장하며, 처음부터 다시 하는 버튼이 있습니다
  • 새 기능: 사이드바의 설치 버튼, 처음 실행할 때 설정이 설치 페이지로 열립니다
  • 새 기능: 저장된 페이지의 편집 막대에 아이콘, 더 명확한 이름(요소 삭제, 강조, 사이드바에 표시)과 도움말이 추가되었습니다
  • 새 기능: 내보내기가 페이지를 내보낸 위치 또는 실패한 이유를 보여 줍니다
  • 변경: Firefox에서 저장과 편집 막대가, Chrome에서 편집 막대가 작동합니다
  • 변경: 설정 가져오기와 내보내기는 현재 설정만 사용하고 더 이상 쓰지 않는 설정은 건너뜁니다
  • 변경: 설정 페이지는 같은 크기를 유지하고 어떤 창 너비에도 맞습니다

    • ScrapBro 1.0.0

    같은 스크랩북을 읽고 쓰는 ScrapBee의 포크인 ScrapBro의 첫 번째 버전입니다.

  • 새 기능: Chromium 기반 브라우저(Chrome, Edge, Brave, Vivaldi)뿐 아니라 Firefox와 그 파생 브라우저(Floorp, LibreWolf, Waterfox)에서도 동작합니다
  • 새 기능: GitHub의 ScrapBro 릴리스에서 다운로드하는 자체 백엔드 프로그램 scrapbro_backend. 기존 스크랩북과 함께 동작하고, 웹 페이지의 요청을 거부하며, 파일을 안전하게 저장하므로 충돌이 나도 반쯤 쓰인 RDF가 남지 않습니다
  • 새 기능: 백엔드 포트가 자동으로 선택되어 설정할 것이 없으며, 사용 중이면 다른 포트가 선택됩니다
  • 새 기능: 더 간단한 설치: 원하는 곳에 저장하는 파일 세 개와 설치 스크립트 하나, 관리자 권한 불필요
  • 새 기능: ScrapBee에서 내보낸 설정을 가져올 수 있습니다
  • 새 기능: 설정의 디버그 옵션으로 로그에 자세한 줄(백엔드 메시지, 저장된 파일, 저장 단계)을 표시합니다
  • 새 기능: 더 알기 쉬운 설정 페이지, 설치 단계에서 파일이 저장된 위치를 보여 줍니다
  • 변경: 경로에 공백이나 괄호가 있는 스크랩북에서도 이제 페이지 아이콘이 표시됩니다
  • 변경: 저장에 실패하면 이유를 보여 주고, 더 이상 페이지가 잠긴 채로 있거나 사이드바에 반쯤 만들어진 항목이 남지 않습니다
  • 참고: ScrapBro와 ScrapBee를 같은 브라우저에서 사용하지 마세요. 둘 다 같은 파일에 기록합니다
