ScrapBro란?

ScrapBro는 웹 페이지나 그 일부를 디스크에 저장하고 브라우저 사이드바에서 정리합니다. ScrapBook 과 ScrapBro가 갈라져 나온 ScrapBee의 데이터를 읽고 쓰므로 기존 스크랩북을 그대로 사용할 수 있습니다. Chrome, Edge, Brave, Vivaldi 등 Chromium 기반 브라우저와 Firefox 및 그 파생 브라우저에서 동작합니다.

중요: ScrapBro와 ScrapBee를 같은 브라우저에서 사용하지 마세요. 둘 다 같은 스크랩북 파일에 기록하므로 함께 사용하면 변경 내용이 사라지거나 스크랩북이 손상될 수 있습니다. 옮겨 오려면 ScrapBee에서 설정을 내보내고 ScrapBee를 제거한 다음 여기서 가져오세요. 그 전에 스크랩북 폴더를 백업하세요.

사용 방법

  • 처음 사용하기 전에

    • 설치 페이지의 설명대로 백엔드 프로그램을 설치한 다음, 구성 페이지에서 RDF 파일을 추가하세요(아래 참고).

  • 저장

    • 사이드바에서 ScrapBro를 열고(도구 모음 버튼에서 "{OPEN_IN_SIDEBAR}") 새 항목을 넣을 폴더를 선택한 다음, 페이지를 마우스 오른쪽 버튼으로 클릭하세요: {CapturePage}, {CaptureSelection}(먼저 텍스트를 선택), {CaptureUrl} 또는 {CaptureAdvance}. 같은 작업이 도구 모음 버튼에도 있으며, 열려 있는 모든 탭을 저장할 수도 있습니다("{CaptureTabs}").

    저장하는 동안에는 사이드바를 열어 두세요(고급 저장 제외). 새 항목은 페이지 저장이 끝날 때까지 회전하는 아이콘을 표시합니다. 항목은 끌어서 옮길 수 있습니다.

  • 읽기와 편집

    • 항목을 클릭하면 저장된 페이지가 열립니다. 저장된 페이지 아래쪽의 막대로 텍스트를 강조하고, 원하지 않는 부분을 지우고, 페이지를 편집해 변경 내용을 저장할 수 있습니다. 항목 옆의 작은 버튼은 페이지의 원래 주소를 엽니다.

    RDF 파일

    RDF 파일은 스크랩북의 목차입니다. 항목과 폴더를 나열하며, 저장된 페이지는 그 옆의 "data" 폴더에 보관됩니다. RDF 파일은 여러 개 가질 수 있고, 각각 사이드바 위쪽의 목록에 나타납니다.

    구성 페이지에서 "+"를 클릭하고 이름과 RDF 파일의 전체 경로를 입력하세요. 예: C:\scrapbooks\news\scrapbook.rdf 또는 /home/me/scrapbooks/news/scrapbook.rdf. 아직 없는 파일은 빈 파일로 만들어집니다.

    백엔드를 직접 실행하기

    보통은 ScrapBro가 백엔드 프로그램을 직접 시작하고(구성 페이지의 "자동") 비어 있는 포트를 선택합니다. 서비스처럼 직접 실행하려면 "수동"을 선택하고 주소를 입력한 뒤 다음 명령으로 시작하세요:

    scrapbro_backend web-server [포트] [호스트] [비밀번호]
    예: scrapbro_backend web-server 9901 127.0.0.1

    비밀번호(영문자와 숫자만)로 백엔드를 보호할 수 있으며, 같은 비밀번호를 구성 페이지에도 입력해야 합니다.

    문제 해결

    먼저 구성 페이지에서 디버그를 켜고 로그를 확인하세요. 백엔드와 주고받은 메시지, 저장된 모든 파일과 저장 단계가 표시되며, 실패하면 오류도 표시됩니다.

    사이드바에 백엔드가 실행 중이 아니라고 표시됨

    보통 로그에 이유가 나옵니다:

  • Specified native messaging host not found: 설치 스크립트를 실행하지 않았거나, 그 뒤에 구성 파일을 옮겼습니다. 프로그램, 구성 파일, 설치 스크립트를 한 폴더에 두고 스크립트를 다시 실행하세요.
  • Access to the specified native messaging host is forbidden: 구성 파일이 다른 ScrapBro 사본의 것입니다. 확장 프로그램을 제거했다가 다시 추가하면 ID가 바뀔 수 있습니다. 구성 파일을 다시 다운로드하고(설치, 2단계) 스크립트를 실행하세요.
  • 시작 직후 Backend disconnected: 프로그램이 없거나 차단되었습니다. 구성 파일 옆에 있는지, 보안 소프트웨어가 삭제하지 않았는지 확인하세요.

    • 변경할 때마다 브라우저의 확장 프로그램 페이지에서 ScrapBro를 껐다가 다시 켜세요.

    브라우저가 프로그램 다운로드를 차단함

    브라우저는 아직 다운로드 수가 적은 프로그램에 경고를 표시합니다. 브라우저의 다운로드 페이지를 열고 파일을 유지하도록 선택하세요. 여기서도 다운로드할 수 있습니다: 백엔드 프로그램 다운로드.

    보안 소프트웨어가 프로그램을 경고함

    일부 백신은 백엔드처럼 서명되지 않은 작은 프로그램을 탐지합니다. 차단되거나 삭제되면 백신의 예외 목록에 추가하세요.

    스크랩북을 불러오거나 저장할 수 없음

  • 구성 페이지의 경로가 올바른지, RDF 파일이 있는지 확인하세요.
  • 스크랩북은 사용자가 쓸 수 있는 폴더에 두세요. 예를 들어 Windows에서는 C:\ 바로 아래는 피하세요.
  • 로그에 "failed to load ... 404"가 표시되면 백엔드가 파일을 찾지 못한 것입니다. 경로를 확인하세요.

    • 포트

    자동 모드에서는 ScrapBro가 포트를 선택하고, 사용 중이면 다른 포트를 사용합니다. 사용 중인 포트는 구성 페이지에 표시됩니다. 수동 모드에서 백엔드가 "address already in use"를 보고하면 다른 포트로 시작하세요.

    그래도 안 되나요?

    브라우저를 다시 시작하면 해결되는 경우가 있습니다. 그래도 안 되면 로그 내용을 첨부해 다음 주소에 문제를 알려 주세요: github.com/unalignedcoder/scrapbro.

    백업

    스크랩북 폴더(RDF 파일과 "data" 폴더)를 정기적으로 백업하세요. ScrapBro는 저장된 페이지를 백업하지 않습니다. RDF 파일을 저장하기 전에 하루에 한 번 이전 버전의 사본을 옆의 "backup" 폴더에 둡니다.
