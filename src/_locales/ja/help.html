ScrapBro とは

ScrapBro はウェブページやその一部をディスクに保存し、ブラウザーのサイドバーで整理する拡張機能です。 ScrapBook と、そのフォーク元である ScrapBee のデータを読み書きできるため、既存のスクラップブックをそのまま使えます。 Chrome、Edge、Brave、Vivaldi などの Chromium 系ブラウザーと、Firefox およびその派生ブラウザーで動作します。

重要: ScrapBro と ScrapBee を同じブラウザーで使わないでください。両方が同じスクラップブックのファイルに書き込むため、 変更が失われたりスクラップブックが壊れたりするおそれがあります。乗り換えるには、ScrapBee から設定をエクスポートして ScrapBee を削除し、ここでインポートしてください。 事前にスクラップブックのフォルダーをバックアップしてください。

使い方

  • 初めて使う前に

    • インストールページの説明に従ってバックエンドプログラムをインストールし、 構成ページで RDF ファイルを追加してください (下記参照)。

  • 保存

    • サイドバーで ScrapBro を開き (ツールバーのボタンから「{OPEN_IN_SIDEBAR}」)、新しい項目を入れるフォルダーを選んでから、 ページを右クリックします: {CapturePage}、{CaptureSelection} (先にテキストを選択)、{CaptureUrl}、 または {CaptureAdvance}。同じ操作はツールバーのボタンにもあり、開いているすべてのタブを保存することもできます (「{CaptureTabs}」)。

    保存中はサイドバーを開いたままにしてください (詳細保存を除く)。新しい項目は、ページの保存が終わるまで回転するアイコンを表示します。 項目はドラッグして移動できます。

  • 閲覧と編集

    • 項目をクリックすると保存したページが開きます。保存したページの下部にあるバーで、テキストのハイライト、不要な部分の削除、 ページの編集と変更の保存ができます。項目の横にある小さなボタンでページの元のアドレスを開けます。

    RDF ファイル

    RDF ファイルはスクラップブックの目次です。項目とフォルダーの一覧を持ち、保存したページはその隣の「data」フォルダーに入ります。 RDF ファイルは複数持つことができ、それぞれがサイドバー上部の一覧に表示されます。

    構成ページで「+」をクリックし、名前と RDF ファイルのフルパスを入力します。 例: C:\scrapbooks\news\scrapbook.rdf または /home/me/scrapbooks/news/scrapbook.rdf。 まだ存在しないファイルは空のファイルとして作成されます。

    バックエンドを自分で起動する

    通常、ScrapBro はバックエンドプログラムを自動で起動し (構成ページの「自動」)、空いているポートを選びます。 サービスとして動かすなど自分で起動したい場合は「手動」を選んでアドレスを入力し、次のコマンドで起動します:

    scrapbro_backend web-server [ポート] [ホスト] [パスワード]
    例: scrapbro_backend web-server 9901 127.0.0.1

    パスワード (英字と数字のみ) でバックエンドを保護できます。同じパスワードを構成ページにも入力してください。

    トラブルシューティング

    まず構成ページでデバッグをオンにし、ログを確認してください。 バックエンドとのメッセージ、保存したファイル、保存の各手順が表示され、失敗したときはそのエラーも表示されます。

    サイドバーにバックエンドが動作していないと表示される

    たいていはログに理由が表示されます:

  • Specified native messaging host not found: インストールスクリプトが実行されていないか、その後に設定ファイルが移動されました。 プログラム、設定ファイル、インストールスクリプトを 1 つのフォルダーに置き、スクリプトをもう一度実行してください。
  • Access to the specified native messaging host is forbidden: 設定ファイルが別の ScrapBro のものです。 拡張機能を削除して追加し直すと ID が変わることがあります。設定ファイルをもう一度ダウンロードし (インストール、ステップ 2)、スクリプトを実行してください。
  • 起動直後の Backend disconnected: プログラムが見つからないかブロックされています。設定ファイルの隣にあるか、 セキュリティソフトに削除されていないかを確認してください。

    • 変更したら、そのたびにブラウザーの拡張機能ページで ScrapBro をオフにしてから再びオンにしてください。

    ブラウザーがプログラムのダウンロードをブロックする

    ブラウザーは、まだダウンロード数の少ないプログラムに警告を出します。ブラウザーのダウンロードページを開いてファイルを保持してください。 ここからもダウンロードできます: バックエンドプログラムをダウンロード。

    セキュリティソフトがプログラムを検出する

    一部のウイルス対策ソフトは、バックエンドのような署名のない小さなプログラムを検出します。ブロックまたは削除される場合は、ウイルス対策ソフトの除外に追加してください。

    スクラップブックを読み込めない、または保存できない

  • 構成ページのパスが正しいか、RDF ファイルが存在するかを確認してください。
  • スクラップブックは、ユーザーが書き込めるフォルダーに置いてください。例えば Windows では C:\ の直下は避けてください。
  • ログに「failed to load ... 404」と表示される場合、バックエンドがファイルを見つけられていません。パスを確認してください。

    • ポート

    自動モードでは ScrapBro がポートを選び、使用中なら別のポートを使います。使用中のポートは構成ページに表示されます。 手動モードでバックエンドが「address already in use」と報告した場合は、別のポートで起動してください。

    それでも動かない場合

    ブラウザーを再起動すると直ることがあります。直らない場合は、ログの内容を添えて次の場所に報告してください: github.com/unalignedcoder/scrapbro。

    バックアップ

    スクラップブックのフォルダー (RDF ファイルと「data」フォルダー) は定期的にバックアップしてください。ScrapBro は保存したページをバックアップしません。 RDF ファイルを保存する前に、1 日 1 回、以前のバージョンのコピーを隣の「backup」フォルダーに保存します。
