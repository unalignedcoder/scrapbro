¿Qué es ScrapBro?

ScrapBro guarda páginas web, o partes de ellas, en su disco y las organiza en la barra lateral del navegador. Lee y escribe los datos de ScrapBook y de ScrapBee, del que es una variante, así que los scrapbooks existentes siguen funcionando. Funciona en Chrome, Edge, Brave, Vivaldi y otros navegadores Chromium, y en Firefox y sus derivados.

Importante: no use ScrapBro y ScrapBee en el mismo navegador. Ambos escriben en los mismos archivos, usar los dos puede perder cambios o dañar un scrapbook. Para cambiar, exporte los ajustes de ScrapBee, desinstálelo y luego impórtelos aquí. Antes, haga una copia de seguridad de sus carpetas de scrapbooks.

Cómo se usa

  • Antes del primer uso

    • Instale el programa backend como se indica en la página Instalación y después añada sus archivos RDF en la página Configuración (vea más abajo).

  • Guardar

    • Abra ScrapBro en la barra lateral (botón de la barra de herramientas y luego «{OPEN_IN_SIDEBAR}»), seleccione la carpeta para los elementos nuevos y haga clic derecho en la página: {CapturePage}, {CaptureSelection} (seleccione antes un texto), {CaptureUrl} o {CaptureAdvance}. Las mismas acciones están en el botón de la barra de herramientas, que también puede guardar todas las pestañas abiertas («{CaptureTabs}»).

    Mantenga abierta la barra lateral mientras guarda (salvo en el guardado avanzado). Un elemento nuevo muestra un icono giratorio hasta que la página se guarda. Los elementos se pueden mover arrastrándolos.

  • Leer y editar

    • Haga clic en un elemento para abrir la página guardada. La barra en la parte inferior de una página guardada permite resaltar texto, quitar partes no deseadas, editarla y guardar los cambios. El pequeño botón junto a un elemento abre la dirección original de la página.

    Archivos RDF

    Un archivo RDF es el índice de un scrapbook: enumera los elementos y las carpetas, y las páginas guardadas están en la carpeta «data» junto a él. Puede tener varios archivos RDF, cada uno aparece en la lista de la parte superior de la barra lateral.

    En la página Configuración, haga clic en «+», escriba un nombre y la ruta completa del archivo RDF, por ejemplo C:\scrapbooks\news\scrapbook.rdf o /home/yo/scrapbooks/news/scrapbook.rdf. Un archivo que aún no existe se crea vacío.

    Ejecutar el backend usted mismo

    Normalmente ScrapBro inicia el programa backend por sí solo («Automáticamente» en la página Configuración) y elige un puerto libre. Para ejecutarlo usted mismo, por ejemplo como servicio, elija «Manualmente», escriba su dirección e inícielo con:

    scrapbro_backend web-server [puerto] [host] [contraseña]
    por ejemplo scrapbro_backend web-server 9901 127.0.0.1

    Una contraseña (solo letras y números) protege el backend, la misma contraseña debe indicarse en la página Configuración.

    Solución de problemas

    Primero active Depuración en la página Configuración y mire el Registro: muestra los mensajes intercambiados con el backend, cada archivo guardado y cada paso del guardado, con el error cuando algo falla.

    La barra lateral dice que el backend no está en ejecución

    El Registro suele indicar el motivo:

  • Specified native messaging host not found: no se ejecutó el script de instalación, o el archivo de configuración se movió después. Ponga el programa, el archivo de configuración y el script de instalación en una sola carpeta y vuelva a ejecutar el script.
  • Access to the specified native messaging host is forbidden: el archivo de configuración es de otra copia de ScrapBro. Ocurre cuando la extensión se quitó y se volvió a añadir, lo que puede cambiar su ID: descargue otra vez el archivo de configuración (Instalación, paso 2) y ejecute el script.
  • Backend disconnected justo después de iniciar: el programa falta o está bloqueado, compruebe que está junto al archivo de configuración y que ningún software de seguridad lo ha eliminado.

    • Después de cada cambio, desactive y vuelva a activar ScrapBro en la página de extensiones del navegador.

    El navegador bloquea la descarga del programa

    Los navegadores avisan de los programas que todavía se descargan poco. Abra la página de descargas del navegador y elija conservar el archivo. También puede descargarlo aquí: descargar el programa backend.

    El software de seguridad señala el programa

    Algunos antivirus marcan programas pequeños sin firmar como el backend. Añádalo a las excepciones del antivirus si lo bloquea o elimina.

    Un scrapbook no se carga o no se puede guardar

  • Compruebe que la ruta en la página Configuración es correcta y que el archivo RDF existe.
  • Guarde los scrapbooks en una carpeta en la que su usuario pueda escribir, por ejemplo no directamente en C:\ en Windows.
  • Si el Registro muestra «failed to load ... 404», el backend no encontró el archivo: revise la ruta.

    • Puerto

    En modo automático ScrapBro elige el puerto y toma otro si está ocupado, la página Configuración muestra el que se usa. En modo manual, si el backend indica «address already in use», inícielo en otro puerto.

    ¿Sigue sin funcionar?

    A veces ayuda reiniciar el navegador. Si no, informe del problema con las líneas del Registro en github.com/unalignedcoder/scrapbro.

    Copia de seguridad

    Haga copias de seguridad de sus carpetas de scrapbooks (archivos RDF y carpetas «data») con regularidad, ScrapBro no copia las páginas guardadas. Antes de guardar un archivo RDF, guarda una copia de la versión anterior en una carpeta «backup» junto a él, una vez al día.
