ScrapBro 1.0.1

  • Nouveau : ScrapBro est disponible en 13 langues : anglais, français, allemand, espagnol, italien, portugais du Brésil, russe, ukrainien, polonais, turc, chinois, japonais et coréen

  • Nouveau : le programme backend est téléchargé depuis la version correspondante, et sa somme de contrôle SHA-256 est vérifiée avant l'enregistrement
  • Nouveau : installation en étapes claires, chaque fichier est enregistré une seule fois où vous voulez, avec un bouton pour recommencer
  • Nouveau : un bouton Installation dans le panneau latéral, et les paramètres s'ouvrent sur la page Installation au premier lancement
  • Nouveau : la barre d'édition des pages enregistrées a des icônes, des noms plus clairs (Supprimer des éléments, Surligner, Afficher dans le panneau) et des infobulles

  • Changement : l'import et l'export des paramètres n'utilisent que les paramètres actuels et ignorent les obsolètes
  • Changement : les pages des paramètres gardent la même taille et s'adaptent à toute largeur de fenêtre

    • ScrapBro 1.0.0

    Première version de ScrapBro, une variante de ScrapBee qui lit et écrit les mêmes scrapbooks.

  • Nouveau : fonctionne dans les navigateurs Chromium (Chrome, Edge, Brave, Vivaldi) ainsi que dans Firefox et ses dérivés (Floorp, LibreWolf, Waterfox)
  • Nouveau : son propre programme backend, scrapbro_backend, téléchargé depuis les versions de ScrapBro sur GitHub. Il fonctionne avec les scrapbooks existants, refuse les requêtes des pages web et enregistre les fichiers de façon sûre, un plantage ne peut pas laisser un RDF à moitié écrit
  • Nouveau : le port du backend est choisi automatiquement, rien à régler, et un autre est choisi s'il est occupé
  • Nouveau : installation plus simple : trois fichiers enregistrés où vous voulez, un seul script d'installation, sans droits d'administrateur
  • Nouveau : les paramètres exportés depuis ScrapBee peuvent être importés
  • Nouveau : l'option de débogage dans les paramètres affiche des lignes détaillées dans le journal (messages du backend, fichiers enregistrés, étapes de capture)
  • Nouveau : page des paramètres plus claire, les étapes d'installation indiquent où les fichiers ont été enregistrés
  • Changement : les icônes des pages s'affichent pour les scrapbooks dont le chemin contient des espaces ou des parenthèses
  • Changement : une capture qui échoue indique la raison et ne laisse plus la page bloquée ni une entrée à moitié créée dans le panneau
  • Remarque : n'utilisez pas ScrapBro et ScrapBee dans le même navigateur, ils écrivent dans les mêmes fichiers
