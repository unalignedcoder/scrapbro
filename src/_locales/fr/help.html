Qu'est-ce que ScrapBro ?

ScrapBro enregistre des pages web, ou des parties de pages, sur votre disque et les organise dans le panneau latéral du navigateur. Il lit et écrit les données de ScrapBook et de ScrapBee, dont il est une variante : les scrapbooks existants continuent de fonctionner. Il fonctionne dans Chrome, Edge, Brave, Vivaldi et les autres navigateurs Chromium, ainsi que dans Firefox et ses dérivés.

Important : n'utilisez pas ScrapBro et ScrapBee dans le même navigateur. Les deux écrivent dans les mêmes fichiers, les utiliser ensemble peut perdre des modifications ou endommager un scrapbook. Pour passer à ScrapBro, exportez les paramètres de ScrapBee, désinstallez-le, puis importez-les ici. Sauvegardez d'abord vos répertoires de scrapbooks.

Utilisation

  • Avant la première utilisation

    • Installez le programme backend comme indiqué sur la page Installation, puis ajoutez vos fichiers RDF sur la page Configuration (voir plus bas).

  • Capturer

    • Ouvrez ScrapBro dans le panneau latéral (bouton de la barre d'outils, puis « {OPEN_IN_SIDEBAR} »), sélectionnez le dossier où placer les nouvelles entrées, puis faites un clic droit sur la page : {CapturePage}, {CaptureSelection} (sélectionnez d'abord du texte), {CaptureUrl} ou {CaptureAdvance}. Les mêmes actions se trouvent dans le bouton de la barre d'outils, qui peut aussi enregistrer tous les onglets ouverts (« {CaptureTabs} »).

    Gardez le panneau latéral ouvert pendant la capture (sauf pour la capture avancée). Une nouvelle entrée affiche une icône animée jusqu'à ce que la page soit enregistrée. Les entrées peuvent être déplacées en les faisant glisser.

  • Lire et modifier

    • Cliquez sur une entrée pour ouvrir la page enregistrée. La barre en bas d'une page enregistrée permet de surligner du texte, de supprimer des parties de la page, de la modifier et d'enregistrer les changements. Le petit bouton à côté d'une entrée ouvre l'adresse d'origine de la page.

    Fichiers RDF

    Un fichier RDF est l'index d'un scrapbook : il liste les entrées et les dossiers, les pages enregistrées sont dans le répertoire « data » à côté de lui. Vous pouvez avoir plusieurs fichiers RDF, chacun apparaît dans la liste en haut du panneau latéral.

    Sur la page Configuration, cliquez sur « + », donnez un nom et le chemin complet du fichier RDF, par exemple C:\scrapbooks\news\scrapbook.rdf ou /home/moi/scrapbooks/news/scrapbook.rdf. Un fichier qui n'existe pas encore est créé vide.

    Lancer le backend vous-même

    Normalement ScrapBro démarre le programme backend tout seul (« Automatiquement » sur la page Configuration) et choisit un port libre. Pour le lancer vous-même, par exemple comme service, choisissez « Manuellement », saisissez son adresse et démarrez-le avec :

    scrapbro_backend web-server [port] [hôte] [mot de passe]
    par exemple scrapbro_backend web-server 9901 127.0.0.1

    Un mot de passe (lettres et chiffres uniquement) protège le backend, le même mot de passe doit être saisi sur la page Configuration.

    Dépannage

    Activez d'abord debug sur la page Configuration et consultez le Journal : il affiche les messages échangés avec le backend, chaque fichier enregistré et chaque étape de capture, avec l'erreur quand quelque chose échoue.

    Le panneau latéral indique que le backend ne fonctionne pas

    Le Journal en donne généralement la raison :

  • Specified native messaging host not found : le script d'installation n'a pas été exécuté, ou le fichier de configuration a été déplacé ensuite. Placez le programme, le fichier de configuration et le script d'installation dans un même répertoire et exécutez à nouveau le script.
  • Access to the specified native messaging host is forbidden : le fichier de configuration est celui d'une autre copie de ScrapBro. Cela arrive quand l'extension a été supprimée puis ajoutée à nouveau, ce qui peut changer son identifiant : téléchargez à nouveau le fichier de configuration (Installation, étape 2) et exécutez le script.
  • Backend disconnected juste après le démarrage : le programme manque ou est bloqué, vérifiez qu'il est à côté du fichier de configuration et qu'aucun logiciel de sécurité ne l'a supprimé.

    • Après chaque modification, désactivez puis réactivez ScrapBro dans la page des extensions du navigateur.

    Le navigateur bloque le téléchargement du programme

    Les navigateurs avertissent pour les programmes encore peu téléchargés. Ouvrez la page des téléchargements du navigateur et choisissez de conserver le fichier. Vous pouvez aussi le télécharger ici : télécharger le programme backend.

    Un logiciel de sécurité signale le programme

    Certains antivirus signalent les petits programmes non signés comme le backend. Ajoutez-le aux exceptions de l'antivirus s'il est bloqué ou supprimé.

    Un scrapbook ne se charge pas ou ne peut pas être enregistré

  • Vérifiez que le chemin sur la page Configuration est correct et que le fichier RDF existe.
  • Gardez les scrapbooks dans un répertoire où votre utilisateur peut écrire, par exemple pas directement dans C:\ sous Windows.
  • Si le Journal indique « failed to load ... 404 », le backend n'a pas trouvé le fichier : vérifiez le chemin.

    • Port

    En mode automatique, ScrapBro choisit le port et en prend un autre s'il est occupé, la page Configuration affiche celui utilisé. En mode manuel, si le backend indique « address already in use », démarrez-le sur un autre port.

    Toujours un problème ?

    Redémarrer le navigateur aide parfois. Sinon, signalez le problème avec les lignes du Journal sur github.com/unalignedcoder/scrapbro.

    Sauvegarde

    Sauvegardez régulièrement vos répertoires de scrapbooks (fichiers RDF et répertoires « data »), ScrapBro ne sauvegarde pas les pages enregistrées. Avant d'enregistrer un fichier RDF, il garde une copie de la version précédente dans un répertoire « backup » à côté de lui, une fois par jour.
