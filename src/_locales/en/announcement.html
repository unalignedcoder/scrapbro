ScrapBro 1.0.1

  • New: ScrapBro is now available in 13 languages: English, French, German, Spanish, Italian, Brazilian Portuguese, Russian, Ukrainian, Polish, Turkish, Chinese, Japanese and Korean
  • New: the sidebar uses the system colors and follows the light or dark theme of the browser, the font is chosen from the installed fonts
  • New: the backend program is downloaded from the release of this version, and its SHA-256 checksum is verified before it is saved
  • New: installation in clear steps, each file is saved once wherever you like, with a button to start over
  • New: an Install button in the sidebar, and the settings open on the Install page on the first run
  • New: the edit bar of saved pages has icons, clearer names (Delete Elements, Highlight, Show in Sidebar) and tooltips
  • New: the exporter shows where the page was exported, or why it failed
  • Change: capturing and the edit bar work in Firefox, the edit bar works in Chrome
  • Change: settings import and export only use the current settings and skip obsolete ones
  • Change: the settings pages keep the same size and fit any window width

    • ScrapBro 1.0.0

    First version of ScrapBro, a fork of ScrapBee that reads and writes the same scrapbooks.

  • New: runs in Chromium browsers (Chrome, Edge, Brave, Vivaldi) as well as in Firefox and its forks (Floorp, LibreWolf, Waterfox)
  • New: its own backend program, scrapbro_backend, downloaded from the ScrapBro releases on GitHub. It works with existing scrapbooks, refuses requests from web pages and saves files safely, so a crash cannot leave a half written RDF
  • New: the backend port is picked automatically, nothing to set, and another one is picked if it gets taken
  • New: simpler installation: three files saved wherever you like, one install script, no administrator rights
  • New: settings exported from ScrapBee can be imported
  • New: the debug option in the settings shows detailed log lines (backend messages, files saved, capture steps)
  • New: clearer settings page, the install steps show where the files were saved
  • Change: page icons now show for scrapbooks whose path contains spaces or brackets
  • Change: a failed capture shows the reason and no longer leaves the page locked or a half created entry in the sidebar
  • Note: do not use ScrapBro and ScrapBee in the same browser, they write to the same scrapbook files
