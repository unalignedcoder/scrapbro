What's ScrapBro?

ScrapBro is a browser extension trying to inherit some properties of ScrapBook, at least, it can read/write data left over from ScrapBook (of course, we can create new). It is a fork of ScrapBee that works in Firefox (and its forks) as well as in Chrome, Edge, Brave and other Chromium browsers, and reads the same scrapbooks as ScrapBee.

Important: do not use ScrapBro and ScrapBee in the same browser. Both write to the same scrapbook files, using both can lose changes or damage a scrapbook. To switch, export the settings from ScrapBee, remove it, then import them here. Back up your scrapbook folders first.

With ScrapBro, you can save web page scraps to local storage, and manage scraps in browser sidebar.

Install and Run Backend Program

ScrapBro needs a "special backend program" to work normally. There are 2 modes to install and start the backend program, automatically or manually, please choose one of them.

  • Install

    • 1. Automatically
    Follow steps in Install guidance page to install backend program for automatically mode.

    2. Manually
    Just click Source 1 to download backend program to your disk.

  • Configure

    • 1. Automatically
    Nothing to set: a free port is picked automatically on first start and kept as long as it stays free.

    2. Manually
    Input web address as backend program service. Format: http://[host]:[port], default: http://127.0.0.1:9901。

  • Run

    • 1. Automatically
    The backend program will be started while starting the browser.

    2. Manually
    Run background program in console before start the browser.

    Command: scrapbro_backend web-server [port] [host]

    For example (Windows):
    cd D:\Download
    scrapbro_backend web-server 9901 127.0.0.1

    Linux or Mac:

    cd ~/Download

    Make sure executable permission added to backend program:
    chmod +x scrapbro_backend

    ./scrapbro_backend web-server 9901 127.0.0.1

  • Password
    • Password can be set to make backend service safer, only 0-9 and a-z are acceptable.

    1. Automatically
    Just input password and save.

    2. Manually
    Input password and save, also need to add password argument when you start backend program:
    scrapbro_backend web-server [port] [host] [password]

    For example (Windows):
    scrapbro_backend web-server 9901 127.0.0.1 secret

    How to use?

    Click on ScrapBro Icon, ScrapBro will be opened in side panel(Mark1), create folders in sidebar if needed.(Mark2)

    Full load the page you want to capture, click on menu item "Capture Page" in content menu to capture the page(Mark3)

    You can also select part of the page, and click on menu item "Capture Selection" to save it(Mark4)

    When capture started, an entity will be showed up in sidebar(Mark5), and it's icon will be showed in status waiting until capture finished, then you can click on the entity to show the local content(Mark6), you can also open origin URL by click on the origin URL button(Mark7).

    When reading a captured scrap, at the bottom of the windows, some buttons can be used to edit the page then save it (highlight some zones in the documents, suppress useless elements).

    Be Ware

    Whatever you are capturing, please keep ScrapBro opened in sidebar (Except advanced saving), entity of scraps captured will be saved to position in sidebar currently selected(if no folder/entity selected, it will be saved to the end of top level). Also, you can move entities around by dragging them.

    Trouble Shooting

    Port

    In automatic mode the port is chosen by ScrapBro: if the last port is taken (e.g. by another browser running ScrapBro or ScrapBee), another free port is picked and remembered, the Log shows the port in use. In manual mode, if you see an error like:
    error: listen tcp :9901: bind: address already in use
    start the backend program on another port, or kill the process that holds it, e.g. under Linux:
    fuser -k 9901/tcp

    File system permission

    Please do not register RDFs under a directory without read/write permission for current user, e.g. common users have no write permission of Windows root directory like c:\, but sub directory of that like c:\foobar works in general.

    Reported as Trojan malware

    The backend program is likely treated as Trojan by scanners, please add it to the white list of scanners to prevent miss-block/mis-kill, please contact me if you have a better solution。

    Download installation scripts fails

    If you can not download the installation scripts for some reason, e.g. mis-blocked by security tools. Please try to re-download the backend:
    Close the browser->Delete files under “DOWNLOAD-DIRECTORY/scrapbro/”->Start the browser->Download again

    If this not helps, please create the scripts manually in “DOWNLOAD-DIRECTORY/scrapbro/” (replace "DOWNLOAD-DIRECTORY" with your real browser download directory).

    Chrome, Edge, Brave, Chromium: scrapbro_backend_chrome.json, replace "EXTENSION-ID" with the ID shown in the extensions page of the browser
    \{
    "allowed_origins": ["chrome-extension://EXTENSION-ID/"],
    "description": "ScrapBro backend",
    "name": "scrapbro_backend",
    "path": "DOWNLOAD-DIRECTORY/scrapbro/scrapbro_backend",
    "type": "stdio"
    \}
    Firefox and its forks: scrapbro_backend_firefox.json
    \{
    "allowed_extensions": ["scrapbro@tuscoss.com"],
    "description": "ScrapBro backend",
    "name": "scrapbro_backend",
    "path": "DOWNLOAD-DIRECTORY/scrapbro/scrapbro_backend",
    "type": "stdio"
    \}
    install.bat (Windows, CODEPAGE UTF-8), registers the JSON files for the current user, no admin rights needed:
    chcp 65001
    reg add "HKEY_CURRENT_USER\Software\Google\Chrome\NativeMessagingHosts\scrapbro_backend" /ve /d "DOWNLOAD-DIRECTORY\scrapbro\scrapbro_backend_chrome.json" /f
    reg add "HKEY_CURRENT_USER\Software\Microsoft\Edge\NativeMessagingHosts\scrapbro_backend" /ve /d "DOWNLOAD-DIRECTORY\scrapbro\scrapbro_backend_chrome.json" /f
    reg add "HKEY_CURRENT_USER\Software\Mozilla\NativeMessagingHosts\scrapbro_backend" /ve /d "DOWNLOAD-DIRECTORY\scrapbro\scrapbro_backend_firefox.json" /f
    echo done
    pause
    install.sh (Linux), copies the JSON file as scrapbro_backend.json into the folder of the browser:
    #!/bin/bash
    chmod +x scrapbro_backend
    mkdir -p ~/.mozilla/native-messaging-hosts
    cp scrapbro_backend_firefox.json ~/.mozilla/native-messaging-hosts/scrapbro_backend.json
    mkdir -p ~/.config/google-chrome/NativeMessagingHosts
    cp scrapbro_backend_chrome.json ~/.config/google-chrome/NativeMessagingHosts/scrapbro_backend.json
    echo done
    install.sh (Mac), the same with the folders "~/Library/Application Support/Mozilla/NativeMessagingHosts" and "~/Library/Application Support/Google/Chrome/NativeMessagingHosts".
