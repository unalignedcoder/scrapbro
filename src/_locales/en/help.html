What's ScrapBro?

ScrapBro saves web pages, or parts of them, to your disk and organizes them in the browser sidebar. It reads and writes the data of ScrapBook and ScrapBee, of which it is a fork, so existing scrapbooks keep working. It runs in Chrome, Edge, Brave, Vivaldi and other Chromium browsers, and in Firefox and its forks.

Important: do not use ScrapBro and ScrapBee in the same browser. Both write to the same scrapbook files, using both can lose changes or damage a scrapbook. To switch, export the settings from ScrapBee, remove it, then import them here. Back up your scrapbook folders first.

How to use

  • Before the first use

    • Install the backend program as described on the Install page, then add your RDF files on the Configure page (see below).

  • Capture

    • Open ScrapBro in the sidebar (toolbar button, then "{OPEN_IN_SIDEBAR}"), select the folder where new entries should go, then right-click on the page: {CapturePage}, {CaptureSelection} (select some text first), {CaptureUrl} or {CaptureAdvance}. The same actions are in the toolbar button, which can also save all open tabs ("{CaptureTabs}").

    Keep the sidebar open while capturing (except for advanced capture). A new entry shows a spinning icon until the page is saved. Entries can be moved by dragging them.

  • Read and edit

    • Click an entry to open the saved page. The bar at the bottom of a saved page can highlight text, remove unwanted parts of the page, edit it and save the changes. The original address of a page opens with the small button next to its entry.

    RDF files

    An RDF file is the index of a scrapbook: it lists the entries and folders, and the saved pages are kept in the "data" folder next to it. You can have several RDF files, each appears in the list at the top of the sidebar.

    On the Configure page, click "+", give a name and the full path of the RDF file, e.g. C:\scrapbooks\news\scrapbook.rdf or /home/me/scrapbooks/news/scrapbook.rdf. A file that does not exist yet is created empty.

    Running the backend yourself

    Normally ScrapBro starts the backend program by itself ("Automatically" on the Configure page) and picks a free port. To run it yourself instead, e.g. as a service, choose "Manually", enter its address, and start it with:

    scrapbro_backend web-server [port] [host] [password]
    e.g. scrapbro_backend web-server 9901 127.0.0.1

    A password (letters and digits only) protects the backend, the same password must be set on the Configure page.

    Troubleshooting

    First turn on debug on the Configure page and look at the Log: it shows the messages exchanged with the backend, every file saved and every capture step, with the error when something fails.

    The sidebar says the backend is not running

    The Log usually tells why:

  • Specified native messaging host not found: the install script was not run, or the configuration file was moved afterwards. Put the program, the configuration file and the install script in one folder and run the script again.
  • Access to the specified native messaging host is forbidden: the configuration file is for another copy of ScrapBro. This happens when the extension was removed and added again, which can change its ID: download the configuration file again (Install, step 2) and run the script.
  • Backend disconnected right after starting: the program is missing or blocked, check that it is next to the configuration file and that no security software removed it.

    • After any change, turn ScrapBro off and on again in the extensions page of the browser.

    The browser blocks the download of the program

    Browsers warn about programs that are not widely downloaded yet. Open the downloads page of the browser and choose to keep the file. You can also download it here: download the backend program.

    Security software reports the program

    Some scanners flag small unsigned programs like the backend. Add it to the exceptions of the scanner if it is blocked or removed.

    A scrapbook does not load or cannot be saved

  • Check that the path on the Configure page is correct and that the RDF file exists.
  • Keep scrapbooks in a folder where your user can write, e.g. not directly in C:\ on Windows.
  • If the Log shows "failed to load ... 404", the backend could not find the file: check the path.

    • Port

    In automatic mode the port is chosen by ScrapBro, and another one is picked if it is taken, the Configure page shows the one in use. In manual mode, if the backend reports "address already in use", start it on another port.

    Still not working?

    Restarting the browser helps sometimes. Otherwise report the problem with the lines of the Log at github.com/unalignedcoder/scrapbro.

    Backup

    Back up your scrapbook folders (RDF files and "data" folders) regularly, ScrapBro does not back up the saved pages. Before it saves an RDF file, it keeps a copy of the previous version in a "backup" folder next to it, once a day.
